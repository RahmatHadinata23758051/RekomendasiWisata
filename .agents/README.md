# Agent Documentation & Guidelines (.agents)

Folder ini digunakan untuk menyimpan dokumen arsitektur, spesifikasi, dan panduan proyek **Recommendation Traveller** untuk semua modul (Data, Scraping, Model ML/AI, Website, API, dll).

## Struktur Dokumentasi

- **`PRD.md`** : Product Requirements Document (Tujuan produk, fitur utama, target pengguna, dan roadmap)
- **`SRS.md`** : Software Requirements Specification (Spesifikasi teknis, kebutuhan fungsional & non-fungsional, arsitektur sistem)
- **`AGENTS.md`** : Aturan dan panduan untuk AI Agent dalam pengembangan repository ini
